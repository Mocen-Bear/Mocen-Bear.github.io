## GitHub 是个啥

一句话：**代码世界的网盘 + 社交网络**。把文件传上去，全世界都能看（如果你愿意），还有完整的「修改历史」帮你记着每一步。

它最核心的单位叫**仓库（Repository）**：一个仓库 = 一个文件夹 + 这个文件夹的全部历史记录。你的博客就是一个仓库。

## 核心名词速查表

| 名词 | 人话解释 |
|---|---|
| Repository（仓库）| 一个项目文件夹，含全部历史 |
| Commit（提交）| 一次「存档」，像游戏存档点 |
| Push（推送）| 把存档好的内容传上网 |
| Pull（拉取）| 把网上最新的内容下载下来 |
| Issue（议题）| 仓库自带的留言板/待办清单 |
| Discussions（讨论区）| 更像论坛的讨论板块（咱博客的留言就在这）|
| Pages | GitHub 免费送的网络空间，专门放网页 |

## 第一步：注册

打开 `github.com` → 点 **Sign up** → 填邮箱和密码 → 收验证邮件 → 完事。全程免费，一个邮箱走天下。

## 第二步：建一个自己的仓库

1. 登录后，右上角 **+** 号 → **New repository**
2. Repository name 起个英文名（比如 `my-blog`）
3. 勾上 **Add a README**（自带一张「说明书」，仓库不发空车）
4. 点绿色大按钮 **Create repository** → 仓库诞生 🎉

## 第三步：网页版就能上传文件

不用装任何软件，浏览器就能干活：

1. 打开你的仓库 → **Add file** → **Upload files**
2. 把文件直接**拖进浏览器**（支持多选）
3. 底下的 **Commit changes** 按钮就是「存档+上传」二合一，点它完事

点完刷新，文件就躺在线上了。想看改了什么、谁改的，点仓库的 **Commits** 一栏，每次存档清清楚楚。

## 和我们博客的关系

- 你的博客 = 仓库里的网页文件，GitHub **Pages** 负责把它变成一个能访问的网站
- 每发一篇文章，就是把 `.md` 文件放进仓库推上去，Pages 自动刷新网站
- 评论区用的 **giscus**，留言就存在仓库的 **Discussions** 里——所以留言板完全免费还不用担心数据丢

## 新手最容易踩的坑

1. 想让 Pages 建网站，仓库得是 **Public**（公开）——建仓库时默认就是，别手滑改成 Private
2. 仓库名、文件名尽量用**英文**，中文容易在网址里变成一串乱码
3. Commit 说明随便写一句都行，但**要写**——三个月后的你会感谢现在留的字条
4. 上传同名文件 = 覆盖，覆盖了别慌，Commits 历史里还能把旧版本捞回来

---

GitHub 的门槛其实就三层：注册 → 建仓库 → 会点绿色的按钮。剩下的都可以边用边学，你的博客已经在替你练手了 🍓
