上一篇我们把博客搭上线了（没看的补课 → [手把手教你搭一个自己的博客](/posts/how-to-build-your-own-blog/)）。今天讲博客的「日常操作」：怎么写文章、怎么发出去。全程只有文本文件和两条命令，比做菜简单。

## 文章的真实身份：一个文本文件

Hexo 博客里，一篇文章就是 `source/_posts` 文件夹里的一个 `.md` 文件。所谓「写博客」，本质就是写文本文件，没有任何神秘仪式。

开新文章有两种方式：

```bash
hexo new post my-first-post   # 自动生成带模板的文件
```

或者手动新建 `my-first-post.md`，效果一样，随你喜欢。

## 开头的「档案卡」（front matter）

文件最上面夹在两条 `---` 之间的部分叫 front matter，是这篇文章的身份证：

```markdown
---
title: 我的第一篇文章
date: 2025-08-11 18:00:00
tags:
  - 随笔
---

正文从这里开始……
```

- `title`：文章标题，中文随便用
- `date`：发布时间，决定文章的排序和归档位置
- `tags`：标签，想多加几个就多写几行 `- 标签名`
- **文件名建议用英文**：文件名会变成网址，`my-first-post.md` → `/posts/my-first-post/`，清爽好记

## 正文：Markdown 速查表

| 想要的效果 | 这么打 |
|---|---|
| 大标题 / 小标题 | `# 标题` / `## 小标题` |
| 加粗 / 斜体 | `**加粗**` / `*斜体*` |
| 分条列表 | 每行开头 `- ` |
| 引用块 | 行首 `> ` |
| 插图 | `![说明](/img/xxx.png)` |
| 链接 | `[点我](https://…)` |
| 代码块 | 前后各一行三个反引号包住 |

> 图片推荐放进 `source/img` 文件夹再用 `![说明](/img/图片名.png)` 引用，路径最稳，搬家也不怕。

## 本地预览 → 发布上线

写完保存，就两步：

```bash
hexo server                  # 本地预览：浏览器打开 localhost:4000
hexo clean && hexo deploy    # 满意了，发布上线！
```

`hexo clean` 专门清理缓存，「改了怎么没变化」的玄学问题十有八九靠它解决。

## 进阶小技巧

- **写一半不想让访客看到**：用草稿。`hexo new draft 我的草稿`，文件会乖乖待在 `_drafts` 文件夹——正式发布时不会出现，预览时执行 `hexo server --draft` 才能看到
- **改旧文章**：找到对应的 `.md` 直接改，保存后重新 deploy 生效
- **文章多了先分类**：档案卡里加 `categories: 学习笔记`，侧栏会自动整理出目录

## 新手最容易踩的坑

1. 忘了写档案卡 → 标题、标签全空
2. 档案卡的 `---` 被误删或多敲一个 → 卡片失效，一段文字直接糊在正文上
3. 文件名带空格或中文 → 网址变成一串乱码
4. 改完文章只保存没发布 → 本地能看，别人看不到（`hexo deploy` 才是真上线）
